# Smart Hospital Patient & Resource Allocation System
~CSC 1012~

A menu-driven C console application simulating patient intake, bed allocation,
emergency triage sorting, and medical billing for a hospital system.

## Features
- Patient registration with input validation
- Automatic bed assignment across 4 wards
- Billing calculation (consultation fee, emergency surcharge, ward cost, age subsidy)
- Priority-based patient sorting (urgency level)
- Performance reports (revenue, occupancy %, top-paying patient)
- Persistent bed status and patient record logging via file I/O

## Built With
